# integrated-master-hub

クロードの成果物移動

**→ [作業者トップページはこちら](https://aimsoaringhaiku.github.io/integrated-master-hub/docs/apps/)**

## 構造

```
docs/
  apps/     ← HTMLアプリ本体（index.htmlがトップ）
  data/     ← JSONデータ
  maps/     ← SVGフロー図
  tools/    ← ツール類
  sub/      ← サブシステム
  templates/ ← JSON分離型ビューア（?target=で切替）
notes/      ← 元資料（TSV・MD・TXT）。docs/ の外、リポジトリ直下
```
